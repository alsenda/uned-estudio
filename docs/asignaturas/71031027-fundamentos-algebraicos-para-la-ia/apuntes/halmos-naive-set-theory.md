# Halmos — *Naive Set Theory*

Texto clásico de teoría de conjuntos «ingenua» de Paul R. Halmos. El libro de la asignatura
(Perán Mazón, *Fundamentos algebraicos para la IA*, sección 1.2, «Teoría ingenua de conjuntos») lo cita
como lectura para quien quiera ampliar los contenidos: «Quien desee ampliar los contenidos puede
consultar el texto clásico de Halmos».

## Cómo leerlo

- Desde **Documentos**, esta ficha tiene un botón que abre el libro en una ventana junto a la web.
- Enlace directo: <https://es.scribd.com/doc/196856585/Halmos-Naive-Set-Theory-pdf>
- Scribd responde con `X-Frame-Options: SAMEORIGIN`, que impide incrustarlo en otra página, por eso se abre
  en su propia ventana. El contenido del libro no se copia a este repositorio, así que el buscador RAG no
  responde con él.

## Con qué parte del temario se relaciona

Tema 1 del libro de la asignatura, secciones 1.1–1.4: lógica y conjuntos, pertenencia, operaciones,
conjunto potencia, tuplas y producto cartesiano, relaciones de orden y funciones. Esas secciones están
resumidas en «Estudiar» (documento «Álgebra · Tema I · Conjuntos, tuplas y funciones»).
