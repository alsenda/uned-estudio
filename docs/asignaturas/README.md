# Asignaturas

Las 49 asignaturas (48 + el Trabajo de Fin de Grado) del [Grado en Ingeniería en Inteligencia Artificial](../general/grado-ingenieria-ia/README.md) (código 7103), organizadas por curso y semestre — cada una con su guía docente oficial descargada en `apuntes/` cuando la UNED ya la ha publicado. Las marcadas *(sin guía publicada)* todavía no tienen guía disponible en la web oficial; se completarán cuando la UNED las publique.
